# Desert Rose

Soft and sophisticated dusty tones.

## Color Palette

| Role | Name | Hex |
|---|---|---|
| Primary | Deep Mauve | `#6D4A54` |
| Secondary | Dusty Rose | `#C48B8B` |
| Accent | Terracotta | `#C77855` |
| Surface | Sandstone | `#EFE2D8` |
| Background | Desert Sand | `#FAF4EE` |
| Text | Rosewood | `#453137` |

## Typography

- **Headers**: Cormorant Garamond — fallback: Georgia, serif
- **Body**: Montserrat — fallback: Helvetica, Arial, sans-serif

## Visual Identity

Sun-faded rose and terracotta over warm sandstone — muted, tactile, and quietly luxurious, with a high-contrast serif for headlines.

**Best for**: Fashion and beauty, interiors, weddings and lifestyle brands, boutique pitches.

## Usage Notes

- Light-mode-first: use `#FAF4EE` as the background with `#453137` text. Primary and Secondary carry headers and structure; Surface fills cards, table stripes, and callout boxes.
- Accent is for emphasis only: highlights, links, key data points, and calls to action — never body text or large fills behind text.
- Body text must always be Text on Background (or Background-on-Primary for inverted blocks); Secondary and Accent never carry paragraphs.
- Charts: series order Primary → Secondary → Accent; gridlines in Surface; axis labels in Text.
