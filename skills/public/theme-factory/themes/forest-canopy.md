# Forest Canopy

Natural and grounded earth tones.

## Color Palette

| Role | Name | Hex |
|---|---|---|
| Primary | Deep Forest | `#1E4634` |
| Secondary | Moss | `#5F7A61` |
| Accent | Lichen Gold | `#C29B57` |
| Surface | Sage Mist | `#E4EAE0` |
| Background | Parchment | `#F7F5EE` |
| Text | Loam | `#26302A` |

## Typography

- **Headers**: Merriweather — fallback: Georgia, serif
- **Body**: Source Sans 3 — fallback: Helvetica, Arial, sans-serif

## Visual Identity

Layered greens under a canopy, warmed by a lichen-gold accent on parchment. Grounded, organic, and quietly confident.

**Best for**: Sustainability reports, outdoor and agricultural brands, wellness content, ESG decks.

## Usage Notes

- Light-mode-first: use `#F7F5EE` as the background with `#26302A` text. Primary and Secondary carry headers and structure; Surface fills cards, table stripes, and callout boxes.
- Accent is for emphasis only: highlights, links, key data points, and calls to action — never body text or large fills behind text.
- Body text must always be Text on Background (or Background-on-Primary for inverted blocks); Secondary and Accent never carry paragraphs.
- Charts: series order Primary → Secondary → Accent; gridlines in Surface; axis labels in Text.
