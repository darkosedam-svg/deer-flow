# Ocean Depths

Professional and calming maritime theme.

## Color Palette

| Role | Name | Hex |
|---|---|---|
| Primary | Abyssal Navy | `#0A2540` |
| Secondary | Tidal Teal | `#17827B` |
| Accent | Seafoam | `#6FC2B4` |
| Surface | Foam | `#E9F1F2` |
| Background | Salt White | `#F7FAFB` |
| Text | Deep Ink | `#10222E` |

## Typography

- **Headers**: Montserrat — fallback: Arial, sans-serif
- **Body**: Open Sans — fallback: Helvetica, Arial, sans-serif

## Visual Identity

Deep navies anchored by teal currents and a soft seafoam accent. Composed, trustworthy, and unhurried — the palette of charts, harbors, and steady hands.

**Best for**: Corporate reports, finance and consulting decks, healthcare, anything that must feel dependable.

## Usage Notes

- Light-mode-first: use `#F7FAFB` as the background with `#10222E` text. Primary and Secondary carry headers and structure; Surface fills cards, table stripes, and callout boxes.
- Accent is for emphasis only: highlights, links, key data points, and calls to action — never body text or large fills behind text.
- Body text must always be Text on Background (or Background-on-Primary for inverted blocks); Secondary and Accent never carry paragraphs.
- Charts: series order Primary → Secondary → Accent; gridlines in Surface; axis labels in Text.
