# Arctic Frost

Cool and crisp winter-inspired theme.

## Color Palette

| Role | Name | Hex |
|---|---|---|
| Primary | Deep Fjord | `#1D3557` |
| Secondary | Ice Steel | `#457B9D` |
| Accent | Glacier | `#A8DADC` |
| Surface | Frost | `#EAF3F5` |
| Background | Snowfield | `#F8FCFD` |
| Text | Polar Night | `#142639` |

## Typography

- **Headers**: Raleway — fallback: Helvetica, Arial, sans-serif
- **Body**: Nunito Sans — fallback: Helvetica, Arial, sans-serif

## Visual Identity

Fjord blues cooled to glacier pale on near-white snowfields. Precise, airy, and modern — cold in temperature, not in tone.

**Best for**: Tech and SaaS decks, scientific reporting, winter campaigns, clean dashboards.

## Usage Notes

- Light-mode-first: use `#F8FCFD` as the background with `#142639` text. Primary and Secondary carry headers and structure; Surface fills cards, table stripes, and callout boxes.
- Accent is for emphasis only: highlights, links, key data points, and calls to action — never body text or large fills behind text.
- Body text must always be Text on Background (or Background-on-Primary for inverted blocks); Secondary and Accent never carry paragraphs.
- Charts: series order Primary → Secondary → Accent; gridlines in Surface; axis labels in Text.
