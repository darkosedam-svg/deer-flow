# Tech Innovation

Bold and modern tech aesthetic.

## Color Palette

| Role | Name | Hex |
|---|---|---|
| Primary | Electric Blue | `#2563EB` |
| Secondary | Cyan Pulse | `#22D3EE` |
| Accent | Violet Surge | `#8B5CF6` |
| Surface | Circuit Slate | `#1E293B` |
| Background | Deep Slate | `#0F172A` |
| Text | Signal White | `#E6EDF7` |

## Typography

- **Headers**: Space Grotesk — fallback: Helvetica, Arial, sans-serif
- **Body**: Roboto — fallback: Helvetica, Arial, sans-serif

## Visual Identity

Electric blue, cyan, and violet cutting through deep slate — a dark-mode-first system that feels like a product launch. High contrast, high energy.

**Best for**: Startup and product launches, developer tooling, AI/ML decks, keynote-style presentations.

## Usage Notes

- Dark-mode-first: use `#0F172A` as the background with `#E6EDF7` text. For a light variant, invert to a near-white background and use Surface/Primary for text and fills.
- Accent is for emphasis only: highlights, links, key data points, and calls to action — never body text or large fills behind text.
- Body text must always be Text on Background (or Background-on-Primary for inverted blocks); Secondary and Accent never carry paragraphs.
- Charts: series order Primary → Secondary → Accent; gridlines in Surface; axis labels in Text.
