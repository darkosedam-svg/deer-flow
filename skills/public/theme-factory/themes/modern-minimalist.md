# Modern Minimalist

Clean and contemporary grayscale.

## Color Palette

| Role | Name | Hex |
|---|---|---|
| Primary | Ink | `#111111` |
| Secondary | Graphite | `#555555` |
| Accent | Signal Red | `#D0342C` |
| Surface | Mist | `#EFEFEF` |
| Background | Pure White | `#FFFFFF` |
| Text | Ink | `#111111` |

## Typography

- **Headers**: Inter Bold — fallback: Helvetica, Arial, sans-serif
- **Body**: Inter Regular — fallback: Helvetica, Arial, sans-serif
- Single-family system: hierarchy comes from weight and size, not typeface changes.

## Visual Identity

A strict grayscale system with one signal-red accent reserved for the single most important thing on any page. Hierarchy comes from weight and space, not color.

**Best for**: Architecture and design portfolios, product specs, engineering decks, editorial layouts.

## Usage Notes

- Light-mode-first: use `#FFFFFF` as the background with `#111111` text. Primary and Secondary carry headers and structure; Surface fills cards, table stripes, and callout boxes.
- Accent is for emphasis only: highlights, links, key data points, and calls to action — never body text or large fills behind text.
- Body text must always be Text on Background (or Background-on-Primary for inverted blocks); Secondary and Accent never carry paragraphs.
- Charts: series order Primary → Secondary → Accent; gridlines in Surface; axis labels in Text.
