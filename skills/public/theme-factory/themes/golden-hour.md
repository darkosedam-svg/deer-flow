# Golden Hour

Rich and warm autumnal palette.

## Color Palette

| Role | Name | Hex |
|---|---|---|
| Primary | Chestnut | `#6E3B23` |
| Secondary | Burnt Sienna | `#C1502E` |
| Accent | Amber Gold | `#E5A33D` |
| Surface | Honey Cream | `#F6E3C5` |
| Background | Candlelight | `#FBF4E8` |
| Text | Dark Umber | `#43281C` |

## Typography

- **Headers**: Libre Baskerville — fallback: Georgia, serif
- **Body**: Raleway — fallback: Helvetica, Arial, sans-serif

## Visual Identity

Chestnut, sienna, and amber like late-afternoon light through turning leaves. Rich and generous, with an heirloom-serif voice.

**Best for**: Food and hospitality, seasonal campaigns, storytelling decks, annual retrospectives.

## Usage Notes

- Light-mode-first: use `#FBF4E8` as the background with `#43281C` text. Primary and Secondary carry headers and structure; Surface fills cards, table stripes, and callout boxes.
- Accent is for emphasis only: highlights, links, key data points, and calls to action — never body text or large fills behind text.
- Body text must always be Text on Background (or Background-on-Primary for inverted blocks); Secondary and Accent never carry paragraphs.
- Charts: series order Primary → Secondary → Accent; gridlines in Surface; axis labels in Text.
