# Midnight Galaxy

Dramatic and cosmic deep tones.

## Color Palette

| Role | Name | Hex |
|---|---|---|
| Primary | Nebula Violet | `#7B2CBF` |
| Secondary | Cosmic Magenta | `#B15EDF` |
| Accent | Starlight Gold | `#F2C879` |
| Surface | Void Indigo | `#1B1035` |
| Background | Deep Space | `#0E0722` |
| Text | Moonbeam | `#EFEAFB` |

## Typography

- **Headers**: Sora — fallback: Helvetica, Arial, sans-serif
- **Body**: Work Sans — fallback: Helvetica, Arial, sans-serif

## Visual Identity

Violet nebulae and a starlight-gold accent suspended in deep space. Dramatic and cinematic — built for dark rooms and big screens.

**Best for**: Keynotes and showcases, entertainment and gaming, astronomy/space content, evening events.

## Usage Notes

- Dark-mode-first: use `#0E0722` as the background with `#EFEAFB` text. For a light variant, invert to a near-white background and use Surface/Primary for text and fills.
- Accent is for emphasis only: highlights, links, key data points, and calls to action — never body text or large fills behind text.
- Body text must always be Text on Background (or Background-on-Primary for inverted blocks); Secondary and Accent never carry paragraphs.
- Charts: series order Primary → Secondary → Accent; gridlines in Surface; axis labels in Text.
